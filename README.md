# 📊 Amazon Sales Analysis Dashboard Using Excel

## 📌 Project Overview

The **Amazon Sales Analysis Dashboard** is a data analytics project built using Microsoft Excel to analyze sales data and generate meaningful business insights.

The project focuses on understanding sales performance, product category trends, customer locations, payment methods, and order status through data cleaning, Pivot Tables, charts, and an interactive dashboard.

## 🎯 Project Objectives

* Analyze overall sales performance.
* Identify top-performing product categories.
* Understand customer purchasing patterns across locations.
* Analyze order status, including delivered and cancelled orders.
* Explore popular payment methods.
* Present key business insights through an interactive dashboard.

## 🛠️ Tools & Technologies

* Microsoft Excel
* Data Cleaning
* Pivot Tables
* Pivot Charts
* Slicers
* Excel Formulas
* Interactive Dashboard Design

## 📂 Project Structure

* **Raw Data:** Original sales dataset containing 1,000 orders.
* **Cleaned Data:** Prepared dataset with additional Month and Day columns for analysis.
* **Pivot Tables:** Summarized sales data for different business categories.
* **Dashboard:** Visual representation of sales performance and key metrics.

## 📈 Key Analysis Areas

1. **Sales Performance:** Analyze total sales across products and categories.
2. **Product Categories:** Compare sales across categories such as Electronics, Footwear, and Bags.
3. **Customer Locations:** Understand sales distribution across different cities.
4. **Order Status:** Examine delivered and cancelled orders.
5. **Payment Methods:** Compare customer payment preferences.
6. **Time-Based Analysis:** Explore sales trends by month and day.

## 💡 Key Skills Demonstrated

* Data preparation and cleaning
* Exploratory data analysis using Excel
* Data summarization with Pivot Tables
* Interactive dashboard creation
* Data visualization
* Business insights generation

## 🚀 Project Outcome

This project demonstrates how Microsoft Excel can transform raw sales data into an organized dashboard that helps users understand sales trends, evaluate business performance, and make data-driven decisions.
